# configs
в этой папке будут размещены конфигурационные файлы и результаты настройки стенда по варианту 4 «Школа»:
postgresql.conf или параметры MS SQL Express — настройки СУБД;
pg_hba.conf или параметры доступа SQL Server — настройки доступа к СУБД;
windows_firewall_rules.txt — правила брандмауэра Windows;
ipconfig.txt — сетевые параметры физического ПК.
